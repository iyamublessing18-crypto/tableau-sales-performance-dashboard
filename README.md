# Sales Performance Dashboard

## Project Overview

This project presents an interactive Sales Performance Dashboard created using Tableau. The dashboard analyzes sales performance, profitability, product sub-categories, monthly sales trends, and shipping costs.

The purpose of the dashboard is to transform sales data into clear visual insights that can support business decision-making.

## Dashboard Preview

![Sales Performance Dashboard](Dashboard%201%20(1).png)

## Dashboard Features

The dashboard includes:

- Sales performance by product sub-category
- Monthly sales trends
- Monthly profit analysis
- Daily shipping cost analysis
- Interactive sales filters
- Sales and profit performance over time

## Key Insights

- Phones and Chairs are among the highest-performing product sub-categories based on sales.
- Sales performance varies considerably across product sub-categories.
- Monthly sales fluctuate throughout the analyzed period, with some of the highest displayed monthly sales occurring toward the end of the period.
- The highest displayed monthly sales value reaches approximately 118,448.
- Monthly profitability varies significantly, including some loss-making periods.
- The displayed monthly profit ranges from approximately -3,281 to 17,885.
- Shipping costs also fluctuate considerably over the analyzed period.
